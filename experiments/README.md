# Experiments

The steps that led to the real app, kept for history. They're not maintained.

- `test_login.py`, `list_playlists.py`, `test_items.py`, `collect_all.py`: first scripts, one per milestone (log in, list playlists, test the playlist-items endpoint, collect every song).
- `show_all.py`: prints the "All songs" view in the terminal from the database.
- `streamlit_prototype.py`: the first interface, built with Streamlit. Needs `pip install streamlit pandas` and is run from the project root with `python -m streamlit run experiments/streamlit_prototype.py`.
